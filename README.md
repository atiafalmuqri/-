# مِعيار

**منصة تحليل بيانات القطاع غير الربحي السعودي**

مِعيار مشروع لتحليل بيانات الجهات غير الربحية، وفحص جودة البيانات، واستخراج وتصنيف المواد من اللائحة التنفيذية وقواعد الحوكمة، مع واجهة لوحة معلومات لعرض المؤشرات والنتائج.

> **تنبيه:** المؤشرات المعروضة لأغراض التحليل والمراجعة، ولا تمثل استشارة قانونية أو حكمًا على امتثال أي جهة.

## بنية المشروع

```text
.
├── index.html
├── run_pipeline.py
├── requirements.txt
├── src/
│   ├── data_cleaning.py
│   ├── governance_analysis.py
│   ├── legal_topic_classification.py
│   └── legal_text_extraction.py
├── notebooks/
├── tests/
├── reports/
├── review/
└── data/
    ├── raw/
    └── processed/
```

> هذه خريطة تنظيمية للمكونات المقصودة، وقد لا تكون جميع المجلدات أو الملفات موجودة في كل نسخة من المستودع.

## مكونات المشروع

- **واجهة لوحة المعلومات:** `index.html` وملف الواجهة العربي الموجود في المستودع.
- **مسار التحليل:** `run_pipeline.py` لتنسيق خطوات التحليل.
- **تنظيف البيانات:** وظائف تجهيز البيانات ومعالجة القيم والنصوص.
- **تحليل الحوكمة:** تحليل المؤشرات والدرجات عند توفر ملف بيانات مناسب.
- **تصنيف الموضوعات القانونية:** تصنيف النصوص وفق الموضوعات المستهدفة.
- **دفاتر التحليل:** ملفات Jupyter للتجارب والتحليل الاستكشافي.
- **الاختبارات:** اختبارات للتحقق من الوظائف الأساسية.
- **التقارير والمراجعة:** مخرجات التحليل وملفات المراجعة، بحسب ما هو متوفر محليًا.

## المتطلبات

- Python 3.12 أو أحدث.
- الحزم المحددة في `requirements.txt`.
- Tesseract OCR مع دعم اللغة العربية عند استخدام استخراج النصوص من ملفات PDF.

### تثبيت OCR على Ubuntu أو Google Colab

```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-ara
```

## إعداد البيانات

ضع ملفات الإدخال محليًا داخل `data/raw/` بعد التأكد من صلاحية استخدامها:

| الملف المتوقع | الاستخدام |
|---|---|
| `regulation_executive.pdf` | اللائحة التنفيذية |
| `governance_rules.pdf` | قواعد الحوكمة |
| `Charities_-_Dashboard_2.csv` | بيانات الجهات |
| `governance_scores.csv` | ملف درجات اختياري عند توفره |

تُحفظ الملفات الوسيطة التي قد تتضمن نصوصًا كاملة أو معلومات عن الجهات داخل `data/processed/` محليًا. لا ترفع البيانات الحساسة أو الملفات التي لا تملك حق إعادة نشرها إلى مستودع عام.

**مهم:** لا تُعامل درجات الحوكمة غير المتوفرة على أنها صفر. إذا لم يتوفر ملف درجات، فيجب توضيح أن تحليل الدرجات لم يُنفذ.

## التثبيت والتشغيل

من مجلد المشروع:

```bash
python -m pip install -r requirements.txt
python run_pipeline.py
```

لتشغيل الاختبارات:

```bash
python -m pytest tests/
```

قد يتطلب تشغيل OCR تثبيت Tesseract وتجهيز ملفات الإدخال أولًا. راجع سجل التشغيل والمخرجات قبل اعتماد أي نتائج.

## الخصوصية وحماية البيانات

- لا ترفع ملفات PDF أو ملفات البيانات الأصلية إلا بعد التحقق من حقوق إعادة النشر.
- لا ترفع كلمات المرور أو مفاتيح الوصول أو ملفات `.env` أو مفاتيح المراجعة الخاصة.
- أبقِ البيانات الوسيطة والمخرجات الحساسة محلية ما لم يكن نشرها مسموحًا.
- تحقّق من ترخيص مصادر البيانات قبل إعادة توزيعها.

## حالة المشروع والتحقق

- أُضيفت بعض أسماء ملفات Python القياسية لتسهيل الاستيراد، مع الإبقاء على النسخ القديمة لتجنب حذف محتوى سابق.
- **هناك فجوة تكامل معروفة:** الملف `src/legal_text_extraction.py` لا يحتوي حاليًا على جميع الدوال التي يستدعيها مسار التشغيل، ومنها `ocr_document` و`parse_articles`.
- لم يُؤكَّد نجاح تشغيل مسار التحليل كاملًا أو الاختبارات الآلية بعد. لذلك لا ينبغي وصف المشروع بأنه اجتاز الاختبارات حتى تُنفّذ فعليًا وتُعالج الأخطاء الناتجة.
- لم يتم تأكيد ربط قاعدة بيانات دائمة أو تخزين دائم للملفات من خلال هذا المستودع وحده.
