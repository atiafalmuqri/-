# مِعيار

**منصة تحليل بيانات القطاع غير الربحي السعودي**

مِعيار مشروع لتنظيم وتحليل بيانات الجهات غير الربحية، وفحص جودة البيانات، واستخراج وتصنيف المواد من اللوائح وقواعد الحوكمة، وعرض المؤشرات والنتائج.

> المؤشرات والتصنيفات مخرجات تحليلية للمراجعة، وليست استشارة قانونية أو حكمًا على امتثال أي جهة.

## هيكلة المشروع

```text
.
├── index.html
├── run_pipeline.py
├── requirements.txt
├── src/
│   ├── __init__.py
│   ├── config.py
│   ├── audit.py
│   ├── data_cleaning.py
│   ├── governance_analysis.py
│   ├── legal_text_extraction.py
│   ├── legal_topic_classification.py
│   └── visualizations.py
├── data/
│   ├── raw/          # ملفات المصدر المحلية
│   ├── processed/    # ملفات وسيطة محلية
│   └── outputs/      # نتائج التحليل
├── notebooks/        # دفاتر Jupyter
├── tests/            # الاختبارات
├── reports/
│   └── figures/      # الرسوم البيانية
└── review/           # مواد المراجعة اليدوية
```

## المكونات

- `index.html`: واجهة الموقع.
- `run_pipeline.py`: تنسيق خطوات التحليل.
- `src/config.py`: إعدادات ومسارات الملفات.
- `src/data_cleaning.py`: تحميل بيانات الجهات وفحص جودتها وتنظيفها دون حذف السجلات بصمت.
- `src/legal_text_extraction.py`: أدوات تطبيع النص العربي؛ يحتاج مسار استخراج المواد من ملفات PDF إلى استكمال.
- `src/legal_topic_classification.py`: تصنيف أولي للموضوعات القانونية لدعم المراجعة البشرية.
- `src/governance_analysis.py`: تحليل نصي ومقارنات استكشافية ومؤشرات توافر درجات الحوكمة.
- `src/visualizations.py`: إنشاء الرسوم البيانية.
- `src/audit.py`: وظائف التدقيق المتاحة في المستودع.
- `notebooks/`: دفاتر التحليل الاستكشافي والتجارب.
- `tests/`: اختبارات المشروع.
- `data/`, `reports/`, `review/`: مجلدات البيانات والمخرجات والمراجعة.

## المتطلبات

- Python 3.12 أو أحدث.
- الحزم المدرجة في `requirements.txt`.
- Tesseract OCR مع دعم اللغة العربية عند تشغيل استخراج النصوص من PDF.

على Ubuntu أو Google Colab، يمكن تثبيت OCR بالأوامر:

```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-ara
```

## إعداد ملفات البيانات

ضع الملفات المطلوبة محليًا داخل `data/raw/` بالأسماء المحددة في `src/config.py`، ومنها:

- `regulation_executive.pdf`
- `governance_rules.pdf`
- `Charities_-_Dashboard_2.csv`
- `governance_scores.csv` (اختياري، إذا توفر ملف درجات مستقل)

لا تُرفع الملفات الأصلية أو البيانات الحساسة إلى مستودع عام إلا بعد التحقق من حقوق الاستخدام والنشر. مجلدا `data/raw/` و`data/processed/` مستثنيان من التتبع عبر Git، باستثناء ملفات `.gitkeep`.

**تنبيه تحليلي:** لا تُعامل درجات الحوكمة غير المتوفرة على أنها صفر. يجب توضيح عدم توفر الدرجات بدل اختلاق قيم أو نتائج.

## التثبيت والتشغيل

من جذر المشروع:

```bash
python -m pip install -r requirements.txt
python run_pipeline.py
```

لتشغيل الاختبارات:

```bash
python -m pytest tests/
```

قد يفشل مسار التشغيل الكامل حاليًا لأن وظائف استخراج وتقسيم المواد القانونية المطلوبة في `src/legal_text_extraction.py` لم تكتمل بعد. لم يتم تأكيد نجاح التشغيل الكامل أو الاختبارات؛ يجب تشغيلها ومعالجة الأخطاء قبل اعتبار المشروع جاهزًا.

## حالة التكامل

- تمت إضافة المجلدات القياسية إلى المستودع للحفاظ على بنية واضحة.
- بعض الملفات القديمة ذات الأسماء التي تحتوي على مسافات أو أرقام ما زالت موجودة لتجنب حذف محتوى سابق قبل مراجعتها؛ لم يتم نقلها أو حذفها عشوائيًا.
- لا يوجد تأكيد في هذه المرحلة على ربط قاعدة بيانات دائمة أو تخزين دائم للملفات.
- ينبغي مراجعة إعدادات نشر الموقع بشكل مستقل عن ملفات تحليل Python.
