# تحليل البيانات للقطاع غير الربحي السعودي

مشروع لتحليل بيانات الجهات غير الربحية وفحص جودة البيانات، واستخراج وتصنيف المواد من اللائحة التنفيذية وقواعد الحوكمة. يتضمن المستودع أيضًا واجهة لوحة معلومات HTML.

> **تنبيه:** النتائج مؤشرات تحليلية للتوعية، وليست استشارة قانونية ولا حكمًا على امتثال أي جهة.

## محتويات المشروع

- `index.html` و`تحليل البيانات للقطاع غير الربحي.html`: واجهة لوحة المعلومات.
- `run_pipeline.py`: نقطة تشغيل مسار التحليل باستخدام Python.
- `src/`: وظائف تنظيف البيانات، واستخراج النصوص، والتصنيف، والتحليل، والرسوم والتدقيق.
- `notebooks/`: دفاتر Jupyter للاستكشاف والتحليل.
- `tests/`: اختبارات آلية.
- `reports/`: التقارير والرسوم النهائية عند توفرها.
- `review/`: ملفات المراجعة. لا ترفع مفاتيح المراجعة أو أي بيانات سرية إلى مستودع عام.

## المتطلبات

- Python 3.12 أو أحدث.
- الحزم في `requirements.txt`.
- Tesseract OCR مع دعم اللغة العربية عند تشغيل استخراج النص من PDF.

### تثبيت Tesseract على Ubuntu / Google Colab

```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-ara
```

## تجهيز ملفات الإدخال

ضع الملفات الأصلية محليًا داخل `data/raw/`، ولا ترفعها إلى GitHub إلا بعد التأكد من صلاحية إعادة نشرها:

| الاسم المتوقع | الاستخدام |
|---|---|
| `regulation_executive.pdf` | اللائحة التنفيذية |
| `governance_rules.pdf` | قواعد الحوكمة |
| `Charities_-_Dashboard_2.csv` | بيانات الجهات |
| `governance_scores.csv` | اختياري؛ ملف درجات مستقل إذا توفر |

تُحفظ الملفات الوسيطة التي قد تتضمن نصوصًا كاملة أو أسماء جهات في `data/processed/` محليًا. لا تُعامل غياب درجات الحوكمة على أنه صفر؛ إذا لم يتوفر ملف درجات، يجب توضيح أن تحليل الدرجات لم يُنفذ.

## التشغيل

من جذر المشروع:

```bash
python -m pip install -r requirements.txt
python run_pipeline.py
python -m pytest tests/
```

قد يتطلب تشغيل مسار OCR تثبيت Tesseract وتجهيز ملفات الإدخال أولًا. لا تعتبر النتائج معتمدة قبل مراجعة سجل التشغيل والمخرجات.

## سياسة البيانات والخصوصية

- لا ترفع ملفات PDF أو ملفات البيانات الأصلية إذا لم تكن حقوق إعادة النشر مؤكدة.
- لا ترفع ملفات المفاتيح، كلمات المرور، ملفات `.env`، أو مفاتيح المراجعة القانونية الخاصة.
- ملفات البيانات الوسيطة والمخرجات الحساسة يجب أن تبقى محلية ما لم يُسمح بنشرها.
- راجع ترخيص كل مصدر بيانات قبل إعادة توزيعه.
